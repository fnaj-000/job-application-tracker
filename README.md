# Job Application Tracker

A full-stack web application designed to organize, manage, and prioritize job applications throughout the job search process. Built as a COP4751 database course project.

## Features

* **Dashboard Overview**: Real-time summary metrics tracking total companies, job listings, active applications, and networking contacts.
* **Companies Management (CRUD)**: Add, view, update, and manage prospective employers and company details.
* **Job Listings (CRUD)**: Track open roles linked to specific companies via relational database joins, including job types and details.
* **Application Tracking (CRUD)**: Record application submissions and monitor progress across interview stages.
* **Networking Contacts (CRUD)**: Store and organize recruiter and professional contact information.
* **Job Match & Ranking Algorithm**: Automatically scores and ranks available job opportunities based on job type, flexibility, and user preferences.

## Technologies Used

* **Backend**: Python, Flask
* **Database**: MySQL (`mysql-connector-python`)
* **Frontend**: HTML5, CSS3, Bootstrap
